HUONG DAN CHAY LOCALHOST TREN MAY TINH:

Cach 1 (Chay Localhost tu dong):
- Tren Windows: Giai nen thu muc nay, sau do nhap dup vao file "start_localhost_windows.bat". Trinh duyet se tu dong mo dia chi http://localhost:8080.
- Tren macOS / Linux: Mo Terminal tai thu muc nay va chay lenh: bash start_localhost_mac_linux.sh

Cach 2 (Mo nhanh khong can cai dat):
- Nhap dup truc tiep vao file "index.html" de mo bang Chrome, Edge hoac Safari. Moi tinh nang loc (Filter), tim kiem (Search), chuyen so do H1/H2 va luu dau tick Checklist deu hoat dong day du.
